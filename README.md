## Deskripsi Project

ATR Learning adalah website pengenalan gagasan
Adaptive Task Recommendation berbasis game quest
2D semi-open world.

Website memperkenalkan konsep asesmen awal,
rekomendasi misi adaptif, pengumpulan kunci,
dan spectator mode secara ilustratif.

## Teknologi

- HTML5
- CSS3
- JavaScript

## Fitur Website

1. Beranda dengan kartu animasi
2. Pengenalan profil tim penggagas
3. Penjelasan awal gagasan
4. Alur sistem interaktif
5. Pengenalan lima karakter petualang
6. Footer profil GitHub

## Cara Menjalankan

1. Clone repository.
2. Buka folder melalui VS Code.
3. Jalankan index.html dengan Live Server.
4. Gunakan navbar untuk menjelajahi website.
